# 誤出荷防止システム (出荷検品 MVP)

スマートフォン（特に Android Chrome）での利用に特化した、サーバ不要・完全クライアントサイド動作の誤出荷防止システム（検品システム）の MVP です。PWA (Progressive Web App) に対応しており、オフライン環境の倉庫内でも安定して動作します。

## 🛠️ 技術スタック

- **フロントエンド:** HTML5, CSS3, JavaScript (ES6+)
- **UIフレームワーク:** Bootstrap 5.3 & Bootstrap Icons (デザインとレスポンシブ対応)
- **QRコード読取コア:** [jsQR](https://github.com/cozmo/jsQR) (ローカルおよびCDNキャッシュにより完全オフライン動作)
- **ハードウェア統合:**
  - **カメラ:** `getUserMedia` による背面オートフォーカスカメラ呼出
  - **音声フィードバック:** Web Audio API による動的シンセサイズ音（OK時：さわやかな高音チャイム / NG時：警告ブザー）
  - **振動フィードバック:** `navigator.vibrate` による物理バイブレーション（OK時：1振動 / NG時：連続警告振動）
- **データ永続化:** `LocalStorage` による直近100件の検品履歴ローカル保存（サーバ不要）
- **履歴データ出力:** UTF-8 (BOM付き) CSV出力機能（Excelでそのまま文字化けせずに開けます）

## 🔍 バーコードデータ抽出仕様

### 1. 社員証 QR
- スキャンした文字列全体をそのまま「作業員ID」として登録します。
- 作業員IDが登録されると、検品スロット（メイン画面）が有効化されます。

### 2. 客先納品書 QR (固定長文字列)
文字列の特定文字位置から各項目を自動抽出します（仕様書に基づく1始まりの文字位置指定）。

| 項目名 | 対象文字位置 (1-based) | JS切り出し範囲 (0-based) | 桁数 | 備考 |
| :--- | :--- | :--- | :---: | :--- |
| **品番** | `127 - 136` | `substring(126, 136)` | 10桁 | **一致判定に使用** |
| **次区** | `156 - 159` | `substring(155, 159)` | 4桁 | 送り先地区など |
| **納期** | `180 - 187` | `substring(179, 187)` | 8桁 | 例：`20260724` |
| **数量** | `192 - 197` | `substring(191, 197)` | 6桁 | 例：`000150` |
| **注文番号** | `204 - 212` | `substring(203, 212)` | 9桁 | 注文管理用 |

*※もしQRのデータ長が212文字に満たない場合は、切り出しエラーを防ぐため、存在する文字数内で柔軟に切り出した上で警告（データ長不足）を画面に表示します。*

### 3. 現品票 QR
- 先頭の **10桁** を「現品票品番」として抽出します（`substring(0, 10)`）。

### 4. 工程流動表 QR
- 先頭の **10桁** を「工程流動表品番」として抽出します（`substring(0, 10)`）。
- **11桁目以降** のすべての文字列を「ロット番号」として抽出します（`substring(10)`）。

## ⚖️ 一致判定ロジック

3つのQRコードがすべてスキャンされた時点で自動的に判定が走ります。

$$ \text{納品書品番} == \text{現品票品番} == \text{工程流動表品番} $$

- **OK（一致）:**
  - 画面背景が **薄緑色** に変化
  - 「**出荷 OK**」の大きな緑色バナーを表示
  - 軽快なOKチャイム音が再生され、端末が1回振動
  - LocalStorageの履歴に「OK」判定として自動保存
- **NG（不一致）:**
  - 画面背景が **薄赤色** に変化
  - 「**品番不一致 (NG)**」の大きな赤色バナーを表示
  - 警告用の低音ブザー音が再生され、端末が複数回（警告パターン）振動
  - 不一致となった具体的な箇所（例: 納品書品番 $\neq$ 現品票品番）を詳細表示
  - LocalStorageの履歴に「NG」判定として自動保存

## 💻 デスクトップやカメラのない環境での動作確認方法

実物のQRコードやカメラがない、あるいはデスクトップブラウザで検証したい開発者や管理者のために、メイン画面の最下部に **「デモ・動作確認用パネル」** を搭載しています。

1. **ワンクリック簡単テスト:**
   - **「OKパターンを読込」ボタン:** 
     自動的に作業員（`EMP-0897`）がログインし、一致するダミーデータ（品番 `ABC-123-X9`、次区 `B-04`、納期 `20260724`、数量 `1250`、ロット `LOT9988776655`）を全スロットに注入し、一瞬で **出荷OK状態（背景緑、音声チャイム、履歴保存）** の挙動を確認できます。
   - **「NG (現品票品番エラー)」ボタン:**
     現品票の品番だけを不一致データ（`XYZ-999-99`）にして注入し、**NG状態（背景赤、警告音、詳細不一致表示、履歴保存）** の挙動を確認できます。
   - **「NG (工程表品番エラー)」ボタン:**
     工程流動表の品番だけを不一致データ（`9999999999`）にして注入し、同様にNGの挙動を確認できます。

2. **直接入力による検証:**
   - 各スロットの「直接入力欄」に値を入力して「設定」を押すことで、任意の文字列を用いて動作確認や、本番同様の固定長仕様テストを行うことができます。

## 📱 PWA (オフライン起動) の設定とAndroid Chromeでのインストール方法

1. **HTTPS環境下への配置:**
   - PWAおよびカメラ（`getUserMedia`）はセキュリティ上、**HTTPS環境下**（または `localhost`）でのみ動作します。
   - 無料のホスティングサービス（GitHub Pages, Vercel, Cloudflare Pagesなど）にこのディレクトリごとアップロードするだけで、即座に暗号化された本番用Webアプリが完成します。
2. **Android Chromeでの起動・インストール:**
   - Chromeブラウザで公開したURLを開きます。
   - 画面上部、またはメニュー（右上の縦の点3つ）から **「アプリをインストール」** または **「ホーム画面に追加」** を選択します。
   - ホーム画面に高解像度の専用アイコン（`icon.svg`）が追加され、次回以降はインターネットがないオフライン倉庫内でも、ブラウザのアドレスバーが表示されない **全画面のネイティブアプリ感覚** で瞬時に起動します。
3. **オフライン動作検証:**
   - インストール完了後、スマートフォンを「機内モード」にして起動してみてください。
   - キャッシュ機能（`sw.js`）により、BootstrapやQRコードライブラリも含めて問題なく起動し、検品や履歴保存、CSV出力などの全機能がそのまま使えます。
